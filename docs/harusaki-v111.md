# ハルサキ村 v1.11
採用された花と風の村を、専用32×32タイル、固定座標、6種の外観SVG（7棟）・7個別室内マップで実装。北出口(15/16,0)→第2街道、南出口→第1街道。噴水2×2と風車に衝突判定、広場を回る道、池に6マスの橋、花壇と4区画の栽培園。生活区と段丘の森の入口も残す。村内の野生戦・釣りは不可。通常の任意練習戦のみ可能。
## 生活
既存人物IDを流用して総2000人を維持し、現地の呼び名と予定を更新。診療所・雑貨店・仕立て工房・冒険教室は24時間。ほかの住民と6系統の相棒は時間帯に応じて広場、花壇、家、商店などに移動。屋外/室内の重複を避ける。人物原画と歩行ベース、アニマ原画は既存採用素材を再利用し、新規の全身NPC原画は作成していない。
## 任意イベント
捕獲記念(キャプセル5)、迷子コムギネ(1000G)、花壇3箇所(水やり、実3種)、練習戦(スプレー3、敗北ペナルティなし/本来の手持ちを復元)、仕立て体験(旅帽)、夜の噴水(会話記録)。すべて一度だけ報酬を受領、進行条件なし。帽子は既存衣装451の外見を利用し、通常販売から除外。試着は購入前に主人公の着用姿を確認できる。
## ジム移設
元の2～50番を1～49番に再番号付けし、旧1番の森ジムを既存のミチシルベ村に移設（新50番）。既存町の名前、元のリーダー/タイプ/バッジ原画、道路・生息テーブル・既存ゲート位置を維持。五圏の地区番号は新番号に追従。最初のバッジによる道具解放と五圏のリーグ条件は維持し、到達性を検査。旧セーブでは取得済みバッジを対応する新番号へ移し、旧村室内位置は村入口へ退避。パズル進捗は初期化する。旧セーブ全体の完全互換は保証しない。
## 素材
obj/harusaki/ に新規6外観SVG、24花壇タイル、20小物のSVGアトラス、風車・噴水ベースを格納。噴水・回転羽根・灯り・水面はCanvasで動的描画。室内装飾は既存の床・家具素材と専用配置を併用。昼と夜の2曲はオリジナルの合成BGM、8効果音はWeb Audio合成（環境音は控えめ）。実際の街のスクリーンショットをChromium/WebKit試験で保存。物理iPhoneは未検証。
