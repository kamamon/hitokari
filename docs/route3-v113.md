# 第3街道 v1.13

トリベル平原（西）からモミノキ街（東）への32×32専用分岐地図。北は草むらなしのトレーナー街道（6人・双子2人の対戦あり）、南は草むら街道（トレーナー0）。中央の樹木と岩の壁で分離し、両端だけで合流する。南ルートはバッジ・トレーナー勝利を要求せず、北は視線バトルと話しかけによる戦闘。1匹しか元気な相棒がいない場合の双子は単戦。敗北時は既存の処理。道具3個と案内看板を配置。

Lv8～11、100分率の抽選。地形のある陸上だけ出現する。他の道路と平原の採用済み出現テーブルは維持。水場はないため釣りと水上の暫定リストは対象外。鍛錬と根の守りは相手からの攻撃/能力低下に対して1戦1回。硬角は通常の威力1～50の物理技1.3倍、固定ダメージは除外。静音飛行は相手の正の優先度を持つ攻撃技に対して無効。再生尾は生存状態で任意交代したとき最大HPの20%回復、強制的な瀕死交代は対象外。岩竜の気迫は効果抜群のダメージを受けた際に1戦1回発動し、次の通常攻撃技の使用時に消費（失敗・命中しない場合も消費、複数回攻撃・範囲攻撃は1技として扱う）。

## 素材と互換性
承認済みの第3道路のオリジナル原画13体を切り出し、背景・ラベル・枠を除去して透過WebP化。mon/route3/manifest.json に元絵の実画素寸法・SHAを保存。新しい13体の専用背面は未制作のため既存の正面反転方式を使用。高DPI戦闘描画と既存32モーションの個別リグへ接続。全1212種の図鑑番号を維持し、採用済み63形態・保留1149形態。旧第三形態は独立した暫定種として保持。旧データの同じIDは新しい種に対応する。最初のジムの街・番号・既存バッジ条件は維持。物理iPhoneは未検証。
