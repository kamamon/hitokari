# Emerald 品質改善 v1.1 — 統合版

並行して main に反映された品質改修（886b8ed）を基準とし、機能を重複させず追加した。既存の6匹表示、終盤6匹編成、戦闘AI、なつき度、遭遇特性、隠し道具、道具分類、図鑑検索、再戦、旧セーブ互換、CIを維持。

追加: 種族値・個体値・努力値・実数値の比較と努力値配分バー、観察した種と回数を場所ごとに記録、訪問済みの系統生息候補と実観察を区別、従来の3連戦に加えて全回復の7連戦とHP/PP持越しの7連戦、ポイント交換、セーブのPP上限チェック。七連戦はLv50・異種3匹・バッグ禁止、対戦終了後は元の手持ちと図鑑に復元。勝利1P、完走+3P。既存の修練場の連続優勝記録は別に維持。

統合コードの19項目のロジック検証を実行済み（node tests/quality-smoke.cjs）。35項目を検証した先行ブランチとはロジックが一部異なる。修練場の勝敗・回復・中断は対戦結果スタブによる検証であり、実画面や戦闘の完走を確認したものではない。

未実装: 2対2戦闘、修練場専用マップ、ジム固有パズル、孵化・預け育成・条件進化・技再習得、秘密基地、栽培、追加素材と音源。実端末での描画・タッチ操作・ゲーム全編完走は未確認。方針は docs/emerald-quality.md を参照。
