# アニマ・クロニクル / Emerald品質向上 設計・進捗
2026-11-27 — phase 1

## 調査と方針
既存の index.html は約6,110行の Canvas 2D ゲーム。README記載: 1212種、50ジム、2000人、492技、200道具、650衣装。既存の性格25・個体値・努力値・特性19、ダメージ、天候、捕獲、飛行、物語等を再利用。参照した資料:
- https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Emerald_Version
- https://bulbapedia.bulbagarden.net/wiki/Generation_III
- https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Emerald%3A_Official_Nintendo_Player%27s_Guide

参考にするのは成長・探索・戦術・再戦の仕組みであり、グラフィック、世界、音源、テキストは独自。既存の5スターター、50ジム・5圏・12守護獣・独自の技別物理特殊分類を保つ。原作全データの移植ではない。

## 今回の変更
- 6体手持ちと6行のカード、殿堂入り表示の3列2段、終盤チーム拡張。既存セーブの手持ち・牧場維持。
- 戦闘AI: 期待ダメージ、KO、命中、吸収特性、状態や段階、回復を評価。ダメージ計算に試算用の確定乱数値を追加。行動中にどちらか倒れたら行動を中断し、ターン終了効果・瀕死判定後に交代。勝敗同時は味方全滅なら敗北。
- なつき度0〜255（初期70、128歩ごと+1、生存個体のLv上昇で+4、瀕死-3）。今回の段階では戦闘性能・進化条件に影響しない。個体画面のAで詳細を切り替える。
- 出現: 夜の霊・闇に1.6倍、昼・朝の森・空に1.25倍、帯電肌の先頭で雷、水呑みの先頭で潮に1.7倍。威圧で遭遇頻度0.65倍、千里眼1.35倍。生息候補の追加や入替はしない。
- まよけは先頭の元気な個体未満のみ抑制、終了後の再利用。花の隠し道具は各対象マップ1回・固定乱数・既存アイテム利用。
- 旅の手帳、道具分類、図鑑検索。人物2000人の収集可能性を保つため既存住民の巡回ロジックを維持。固定配置や時間割は次段階。
- 再戦: 勝敗の記録、256/512歩のクールダウン、Lv上昇は上限付き、同じバッジや技書は再取得しない。旧セーブは総歩数を基準とする。
- 修練場単戦の塔: 3体選択、Lv50にそろえ、3連戦・回復なし・バッグ禁止、経験値/賞金/図鑑登録なし。勝敗後に手持ちを復元する。3戦1セットで連覇記録。初回は仮のメニュー入口で、専用マップは次段階。
- セーブキーを保持、v4移行、直前の正常なセーブを別キーに残す。失敗時の手動保存通知、入力中のキーボード・ポインター解除改善。

## 検証
純粋な補助関数は Node テスト、既存インラインJSの構文チェック。CIのブラウザー試験は title 起動・セーブ・編成・戦闘等。実機および全編の完走は別途必要。


## 第2段階：育成・孵化（実装）
- 育成牧場はバッジ2個からメニュー利用。親はS.boxから専用保管領域に移し、同系統2体まで。256歩で卵、受け取って512歩で孵化。卵1個は手持ちとは別枠、孵化時空きがなければ牧場。個体値3枠を無重複抽選で両親から継承、性格50%親のどちらか、特性60%親のどちらかを継承抽選する。親は歩数経験値（上限20000）を持ち帰る。性別・異種間繁殖・卵技・道具補正は未実装。
- 特性: 通常系統に決定論的な第二候補を付与。新規個体の25%で第二特性を選択。旧個体の特性に変更なし。種族の主特性は固定、進化後も個体特性を維持。
- 早期進化: ネムヤギ(夜・絆190)、マキレイ(夜)、ポンケン/フワマユ(絆180)、カゲムスビ/セイガリュウ(夜)、ミミフウ(朝)、ヒマトカ(昼)。初期形態のみ、通常条件の4〜5レベル前から。ゲーム内の生態説明から選定した独自仕様。
- セーブ検証に親と卵のデータ、歩数境界検証を追加。上記をもって完全な孵化・多特性・分岐育成が完成したわけではない。


## 第3段階：雰囲気とゲームルールを連動（実装）
- 10場面の独自短曲をWebAudioで生成。外部音源を使用・複製しない。和音の分散、旋律、ベース、戦闘時の打音を組み合わせる。独立BGM音量・オンオフ、タップ等でAudioContext開始/再開。
- 気候: 町・屋内・序盤・修練場を除外し、対象パレットの約40%を決定論的な天候マップとする。マップの雨/砂/雪/日ざしとバトルの天候（持続、タイプ補正、残留ダメージ）を同一ルールで扱う。技で上書き後は従来の5ターン制。自然天候の復帰は同一バトル中には行わない。
- アクセシビリティ: 点滅を減らし、画面揺れを無効化する選択。OSのprefers-reduced-motionにも対応。全演出の完全な低刺激化を保証するものではない。


## 第4段階：全面拡張

- `advanced-combat.js`: 4つの場スロット、対象選択、優先度/素早さの行動順、交代予約、範囲技（16種の対象指定、2体に当たると75%）、回復/治療の味方指定、瀕死の補充、天候・壁・状態のターン処理。既存の技・効果をペアビューで再利用。対人戦の一部と第5の倍数のジム、双戦施設で起動。2体未満は単戦にフォールバック。単戦と双戦で相性、残HP、想定ダメージを基に敵交代を評価。範囲技は敵のみ対象、ダブルの戦闘バッグ・味方への攻撃・野生ダブル・2人のNPC同時視線は未実装。
- `world-expansion.js`: 50ジム、10種のルール（順序、灯火、連動、記憶、重量、色、足跡、相性、時限、回転）と地区固有の配置/解。段丘・瀑布・入江の追加マップに高低差・階段・一方通行段差・橋・滝・海底を設置。従来マップには安全な候補の池に小橋を追加。既存道路の全面手作り化ではない。
- 秘密基地は1か所、家具3枠/7種、移設と回復。実5種、歩数/経過時間の成長、水やりと収穫、回復・治療・絆・演技補助。彩華祭5種4ランクは実技5回の得点競争。通信や他プレイヤーの訪問は未実装。
- 殿堂入り後の専用修練場は単戦7、双戦7、貸出3、持久5戦と交換受付。既存個体の複製を使い、Lv50で戦い、成績/BP以外の戦闘結果を持ち帰らない。
- 町の住民はホーム位置周辺を歩き、目的地を予約して衝突回避。既存の人物ローテーションは維持。5章の導入イベントは既存メインストーリーに追加。
- `animation-enhancement.js` と SVG素材3枚: 体型別変形、歩行と跳躍、技の予備/着弾エフェクト、アイコン43・技粒子34・地形8。元のイラストを活用するため、全1212種の個別スケルトン、原画差し替え、全2000人の方向別新規絵は未実装。
- 旧セーブは意図的に破棄しないが、互換保証はしない。ブラウザー試験では新規セーブ・全ジムの論理検証・地形/施設のマップ生成・戦闘処理の統合テストを追加。実機や全編の人手プレイは別途必要。

## v1.5 全個別データ・戦闘とモバイル品質

### 実装
- data/anima-motion.js: 1212個体種に各9クリップ×5キー、固有の継続時間・振幅・体型・生態。既存原画を帯状に変形して描く。アクションイベントから実際の戦闘・連れ歩き・図鑑に接続。個別の原画作画、骨格付きスプライトの全面新規制作とは異なる。
- data/npc-schedules.js: 全2000人物に職種別かつ固有時刻の24時間予定、速度・夜勤・地区。53生活区、4区域、時間帯に合わせた実際の移動・会話、人物図鑑から予定確認。物語人物の必須配置は保護し、生活区での登場は進捗で解放。主人公として選んだ1名はNPC対象外。
- data/field-designs.js: 870の実マップID別設計（既存屋外331、室内486、追加生活区53）。182の安全な追加小径の計画、景観点、名所、色調を固定。地形は既存マップと生態に合わせた手続き生成データで、全マップ手作業デザインではない。
- 野生ダブル: 通常陸上15%、段丘24%、水上10%（元の遭遇後の追加抽選、手持ち生存2体以上）、まよけを両方へ適用。個別キャプセルと消費予約、逃走、捕獲済み個体の除外、経験値/牧場登録。トレーナー同時視線、対向する共闘組の配置、各トレーナー固有の控えと両者の勝利記録。
- iPhone向け: 独立した横画面コントローラー領域、safe-area/visualViewport、Canvas直接メニュー選択、pointer capture、描画解像度の上限・自動軽量化、画像LRU。動作診断のp50/p95とfpsは稼働中の端末で収集する。

### 検証の範囲
全データと画像ファイルの網羅、全マップ生成・登録、生活区と時間帯、野生/共闘バトルをブラウザー試験。物語は新規開始から初期相棒、50ジム、静環団、守護獣、リーグ、エンディングを実際のイベント・戦闘ルールで通過する。高速化のため画面演出待ち・入力・地点移動を自動化し、高レベル検証編成を用いる（通常の人手プレイ完走ではない）。WebKitはLinuxのiPhoneデバイスプロファイルであり、物理iPhoneのSafari実機とは異なる。測定値はCI環境値として保存する。


## 第6段階：アニマ演技・素材刷新

- 既存正面原画1,212枚、実背面原画27枚を再利用。新規に全1,212種の個体別リグ（体型・生態の特徴・頭部/脚/二次運動ゲイン・支点・歩行速度・体重感・成長段階）を明示データ化。2D原画のアルファ付き連続逆メッシュによる変形で、部位別動作を合成。10体型と17動作、既存9タイムラインの個体差を軽くブレンド。被弾時は絵を点滅消去する方式を廃止。
- SVGアトラス3枚、264コマ（17タイプのエネルギー136、接地/水流/翼の運動80、感情48）。描画順・アニメーション位相に合わせてバトル/フィールドで実使用。低刺激設定では追加演出・変形を停止する。
- 端末上で必要な透明ラスターフレームだけ生成。解像度72/80/112/144、ループ/アクションを8〜12位相に分け、キャッシュ4〜12MiBを上限にLRU。端末設定に応じ1〜3枚/論理フレームの生成制限。解像度切替時キャッシュクリア。表示中に素材が未準備なら原画にフォールバック。
- 観察室と透過PNG素材生成。標準17×8、1コマ160×160。書き出しは現在の2D原画を変形した素材であり、新しい手描きの角度や独立した解剖学的パーツ、3Dモデルではない。背面原画がない種は反転と明示。PNG保存は実ユーザーのリンク操作、iOS共有APIは対応端末のみ。
- `tools/bake-anima-sheets.cjs` は全種/個体指定の素材書き出しツール。既存のセーブスキーマ、戦闘判定、NPC、進行を変更せず、回帰テストを追加。iPhone実機での描画速度は未計測。WebKitはシミュレーションであり実機とは別。
