# 第4街道 v1.15
モミノキ街（北）→ツユクサ野（南）の接続は維持。本道32×32と奥地32×32。川、滝、2段の高低差、階段、複数の木橋、花畑、休憩所。本道はジム未制覇でも通行可能。万能工具で西側の茂みを開く任意ルート、保存される橋修理（板材3個、600G）、観察記録。トレーナー5人、道具6個（4個の拾得＋2個の隠し道具）。水上移動と釣りは既存の解放条件に従いアワトビのみが出現。
