# アニマ・クロニクル ― カンテラの旅人 ―

スマホのブラウザで遊べる、洋風ファンタジーのモンスター育成RPGです。
カンテラの灯でふしぎな生きもの「アニマ」と絆を結び、16のギルドと「栄冠への道」をこえて、ルミエール大陸の王者をめざします。

## 遊ぶには

GitHub Pages を有効にすると、スマホからそのまま遊べます。

1. このリポジトリの **Settings → Pages** を開く
2. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
3. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります

ホーム画面に追加すると、全画面のアプリのように遊べます。進み具合は端末に保存されます
（メニューの「きろくする」。町や建物を移動したときにも自動で保存されます）。
機種変更などに備えて、メニューの「せってい → セーブを書き出す」で文字として控えておけます。

※ 図鑑1200種に入れかえたとき（2026-11-19）にアニマの番号が変わったため、それより前のきろくは引きつげません。それ以後のきろくはそのまま使えます（伝説を入れかえたぶん、以前の伝説をつれていた場合はその子だけいなくなります）。

## 操作

| 操作 | 内容 |
| --- | --- |
| 十字パッド | 移動。円のどこを触っても方向が決まり、指をすべらせて向きを変えられます |
| 画面をなぞる | 移動（パッドの代わり） |
| A / 画面をタップ | 話す・しらべる・決定 |
| B | キャンセル。おしながら移動で走る |
| MENU | メニュー（博物誌・アニマ・もちもの・あずかり牧場・自転車・地図・相性表・きせかえ・きろく・せってい） |
| 自転車 | 自転車を手に入れると出るボタン。乗る・おりる |

パソコンでは 矢印キー / Z（決定）/ X（キャンセル・走る）/ M（メニュー）/ C（自転車）で遊べます。

## 内容

- アニマ 1212種（すべてオリジナル）。色違いあり
  - **ぜんぶ「オリジナル進化図鑑1212」の子たち**です。図版の絵をそのまま切りぬいて使い、名前・タイプ・進化の順番・生態の文も図鑑どおり
    （3段階に進化する399系統＋進化しない特別な3種＋伝説12体。最初にもらえる子は コケバク／ヒノコロ／アメカサネ／デンヒレ／スナヒレド）
  - 図鑑の「フェアリー」はゲームに無いタイプなので「念」として扱います。石や時間帯などLv以外の進化条件は、Lvでの進化に置きかえています
- **伝説の守護獣12体**（No.1201〜1212）。図鑑の伝承をもとに、出会える条件を物語にしています
  - 遺跡の奥には石碑があり、条件をみたすまでは「言い伝え」だけが読めます。読んだ言い伝えは「博物誌 → 守護獣の言い伝え」でいつでも見返せます
  - 世界の三守護：ストラヴェル（最初に会える）・アビサローネ（波をわたる道具を手に入れたあと）→ ふたりに出会うとガイアレグナ
  - 命の巡り：ヒュミナロア（40種をなかまに）→ ヴェルナギア ／ メタモルシア（最後まで進化した子を連れていく）
  - 心の三守護：ソムニアーク（灰の結社の事件を解決）・メモルディア（200種を見つける）→ 王者になるとオルタゼノア
  - 天象の三守護：セレノクシア（物語で目ざめる）・ヘリオヴァン（王者になったあと）→ ふたりを見とどけるとテンキュラシア
  - 12体はそれぞれ図鑑の「専用技」をおぼえています（その子だけの技。技の書にはなりません）
- 能力は、体つき（かたい・すばやい・力もち・ふしぎ・バランス）とタイプから1体ずつ決めています。進化すると得意な能力がより伸びます
- 個体値：野生の子はどの子にも得意な能力がひとつ。進化しない特別な子などは3つが最高。最初にもらう子はどれも高め。「つよさ」の画面でめやすが見られます
- タイプ17種
- 技は492種（うち12は伝説の専用技）。技ごとに「物理・特殊・変化」の分類があり、どのタイプにも物理と特殊の技がそろっています
  （物理は こうげき と ぼうぎょ、特殊は とくこう と とくぼう で計算。同じタイプでも物理が得意な子と特殊が得意な子がいます）
- 連続攻撃・先制・反動・ピンチで強くなる技・決まった量のダメージ、守り・天気（日ざし／雨／砂あらし／あられ）・光の壁・タネ・回復など、効果もいろいろ
- 町の店ごとに ちがう「技の書」を5さつ売っています
- 相性表はメニューからいつでも。タイプをえらぶと「攻めるとき／受けるとき」の 2倍・半分・無効 が一目でわかり、全体の表にも切りかえられます
- 手持ちは4匹まで。それ以上は牧場へ（メニューからいつでも会えます）
- ボールの代わりに「カンテラ」をかかげ、灯りで絆を結ぶ（弱らせる・状態異常にすると結びやすい）
- 最初に選べるアニマは5種
- 町47、街道107、原野・洞くつ・遺跡60以上の広い大陸
- ギルド16、栄冠への道は6階層、四騎士と王者
- 灯を消してまわる「灰の結社」との対決をえがくストーリー
- タイプごとに専用の技エフェクト（威力に応じて4段階）
- 戦う場所で変わる背景、戦闘中に動いてまばたきするアニマ
- 人物はリアルな頭身。主人公・町の人・トレーナー・ギルドマスターをそれぞれ描き分け、
  戦いのはじめには相手のトレーナーと主人公の後ろ姿が登場します
- 風にゆれる木と草むら、足あとや波紋、雪・木の葉・火の粉などの空気感

### いまどきの遊びやすさ

- 着せかえ（体格・肌・目の色・髪型9種・髪の色・ぼうし8種・上着7種・ボトムス・くつ）。旅のはじめと、メニューからいつでも
- 自転車（最初のギルドでもらえます）
- 連れ歩き（先頭のアニマがうしろをついてきます。話しかけることもできます）
- けいけんちは手持ちのみんなに分配、絆を結んだときにも入る
- 技をえらぶときに 物理／特殊 と 相性のめやすを表示
- 技の書は何回でも使える
- 昼と夜（端末の時計にあわせて景色が変わります）
- オートセーブ

連れ歩き・けいけんちの分配・昼と夜・オートセーブは「せってい」で切りかえられます。
