# 一狩り

スマホのブラウザで遊べる、3D視点の狩猟アクションゲームです。
大型モンスターを狩り、剥ぎ取った素材で武器や防具を作って、さらに強いモンスターに挑みます。

## 遊ぶには

GitHub Pages を有効にすると、スマホからそのまま遊べます。

1. このリポジトリの **Settings → Pages** を開く
2. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
3. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります

ホーム画面に追加すると、全画面のアプリのように遊べます。進み具合は端末に自動で保存されます。

## 操作

| 操作 | 内容 |
| --- | --- |
| 画面の左側をなぞる | 移動(上に倒すと画面の奥へ進む) |
| 攻撃 | 連打でコンボ。弓は長押しで溜めて離す |
| 特殊 | 武器ごとの技(ガード・溜め・修羅化・強射) |
| 回避 | 転がって避ける。出始めは無敵 |
| 🎯 | ロックオンの切り替え。解除中は画面の右側をなぞって視点を回せる |
| ◀ 道具 ▶ | 道具を選んで使う |

地面に出る赤い範囲は攻撃の予兆です。塗りつぶされる前に外へ出るか、回避ですり抜けてください。

## 内容

- 大型モンスター 7種(すべてオリジナル)、小型モンスター
- 武器 5種(片手剣・大剣・双剣・ハンマー・弓)、武器 85本、防具 11シリーズ
- クエスト 21本(狩猟・採取・討伐・連続狩猟・歴戦の個体)
- 部位破壊、尻尾切断、怒り、罠と捕獲、斬れ味、調合、食事、スキル

## ファイル

- `index.html` … ゲーム本体(プログラムはすべてこの1枚に入っています)
- `three.min.js` … 3D描画ライブラリ [three.js](https://threejs.org/) r149(MITライセンス)

`three.min.js` が読み込めない環境では、自動で見下ろし型の2D表示に切り替わります。
設定から「見下ろし視点(2D)」「軽量表示」を選ぶこともできます。
