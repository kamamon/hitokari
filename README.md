# アニマ・クロニクル ― ソラネ地方・十二の巡環 ―

スマホのブラウザで遊べる、モンスター育成RPGです。
50の地区と五つの巡回圏からなる「ソラネ地方」を旅して、1212種のアニマと2000人の人びとを「巡環図鑑」に記していきます。

アニマの絵（オリジナル進化図鑑1212）と、人物・衣装・道具の絵（ソラネ地方 完全図鑑）、マップや画面の素材（マップ用キャラクター素材・追加素材カタログ）は、どれも作者の素材をそのまま切りぬいて使っています。

## 遊ぶには

GitHub Pages を有効にすると、スマホからそのまま遊べます。

1. このリポジトリの **Settings → Pages** を開く
2. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
3. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります

ホーム画面に追加すると、全画面のアプリのように遊べます。進み具合は端末に保存されます
（メニューの「きろくする」。町や建物を移動したときにも自動で保存されます）。
機種変更などに備えて、メニューの「せってい → セーブを書き出す」で文字として控えておけます。

※ ソラネ地方への作り直しで世界がすっかり変わったため、それより前のきろくは引きつげません（はじめからになります）。

## 内容

### ソラネ地方
- 50地区・五つの巡回圏（芽吹き圏／潮風圏／炉峰圏／星霜圏／環都圏）。町53、街道と原野・洞くつ・遺跡
- **ジムは50**。リーグに進むのに必要なバッジは、五つの圏で2個ずつの合計10個。どのジムから回るかは自由です
- 圏のさかいには関所があり、その圏のバッジ2個で通行章がもらえます。50のジムをすべて回ると「五圏巡回章」
- 四天王（地脈・潮流・天候・記憶）と、決まったタイプを持たないチャンピオン

### マップと空の旅
- マップの上では、人物はみんな **2頭身**。主人公は4方向に歩くすがたで、自転車・釣り・水の上（水のアニマに乗る）にも対応しています
- **空を飛ぶ**：バッジ3個でもらえる「帰路ホイッスル」を吹くと（メニューの「空を とぶ」でも）、鳥のアニマが来て背中に乗れます
  - 町へのワープではなく、マップの上を そのまま飛んで移動します。木の上も水の上も こえられ、野生のアニマにもトレーナーにも出会いません
  - 降りられるのは **歩ける場所の上だけ**（Aボタン）。降りられる所では 足もとに 白い輪が出ます
  - 道がつながっている方向の はしまで飛ぶと、となりの場所へ そのまま飛んで行けます
  - 関所や まだ ひらけていない道の先、洞くつ・遺跡・塔の中、建物の中へは飛んで行けません（入口に降ります）。物語の順番は 歩くときと 同じです
- 地面・道・草むら・木・建物・置き物・室内の床や家具は、素材集の絵と模様で描いています（地方ごとに 草原・森・海辺・湿地・砂漠・火山・遺跡・雪原・高峰）

### 人物2000人
- 素材集の2000人が、名前と役割つきで登場します（博士、ライバル3人、ジムリーダー50人、四天王、静環団、各地区の住民・職人・研究員・トレーナーなど）
- 会話でも戦闘でも、素材集の絵をそのまま使っています（会話のときは顔と名前・役割が出ます。主要人物15人は 表情つきの顔）
- 各地区に39人。町の人は、町をたずねるたびに顔ぶれが入れかわります
- **人物図鑑**：出会った人が圏・地区ごとに記録されます（メニューの「巡環図鑑」→「人物図鑑」）

### 物語「十二の巡環」
- 変化を止めれば災害も別れもなくせると考える「静環団」が、世界の十二の巡りを固定しようとします。観測・構造・記録の3人の幹部と、代表レムナ
- **守護獣12体**は、素材集の「準備 → 行動 → 出会い」で出会います。遺跡の奥にいる案内人が準備をたしかめて「伝説の道具」をわたし、奥の装置で使うと守護獣が姿を見せます
  - 準備の多くは、各地の人から記録（天文記録・風向記録・海流の記録・種の記録など）を写させてもらうことです
  - 進みぐあいは「巡環図鑑」→「守護獣の記録」で見られます

### アニマ1212種
- 「オリジナル進化図鑑1212」の絵・名前・タイプ・進化・生態をそのまま使っています（3段階に進化する399系統＋進化しない3種＋守護獣12体）
- 図鑑の「フェアリー」はゲームに無いタイプなので「念」として扱います。Lv以外の進化条件はLvでの進化に置きかえています
- タイプ17種、技492種（物理・特殊・変化。うち12は守護獣の専用技）、天気・壁・連続攻撃など
- 能力は体つきとタイプから1体ずつ。個体値は「つよさ」の画面でめやすが見られます

### 道具200種
- 素材集の200種すべてに、絵とはたらきをつけました
  - 回復とケア、旅の道具（しげみを切る・水をわたる・空を飛ぶ・診療所へもどる など）、キャプセル25種（タイプや時間帯などの得意な条件つき）
  - 進化の道具（タイプの合うアニマを少し早く進化させる）、持ち物（アニマに持たせると技の威力や素早さが上がる など）
  - 研究の道具、物語の鍵、守護獣に出会うための伝説の道具12種
- 店の品ぞろえは地区ごとに少しずつちがいます

### 衣装650種
- 帽子・アクセサリー・トップス・ボトムス・靴・バッグを、主人公の絵に重ねて着せかえできます（メニューの「きせかえ」）。上下とも着がえると、素体の絵を下地にします
- 衣装は、町の店にいる仕立ての職人から買えます。地区ごとに13着ずつ、50地区で650着

### そのほか
- 手持ちは6匹まで（それ以上は牧場へ）、けいけんちの分配、連れ歩き、自転車、釣り、昼と夜、オートセーブ
- 画面の素材：タイトルのロゴと絵、アプリのアイコン、戦闘の背景14種、主人公とアニマ27種の後ろ姿、バッジ50個と圏・リーグ・静環団の紋、タイプ・状態・天気・メニューの絵記号、技の粒、窓と手持ちのわく、十字パッドとA・Bボタン、図鑑・人物図鑑・きせかえの背景、地方の地図

## 素材集とちがうところ

- 地区の名前と ジムのタイプは、追加素材カタログの一覧（ハルサキ村・森 〜 テンカイ門・辰）にそろえました。図鑑の「フェアリー」は「念」です
- マップの2頭身は、主人公は マップ用素材の歩行シート、ほかの人物は 立ち絵から自動で作っています（横向き・後ろ向きの絵がある主要人物8人は その絵から）
- 着せかえは 位置を自動で合わせています。マップの2頭身には 着せかえは出ません（旅券・きせかえ画面・戦闘の前に出ます）
- 追加素材のうち JSON・CSV・atlas.json・効果音は PDF に入っていなかったため使っていません。搭乗位置などは絵から読み取って合わせています
- 主人公の等身の歩き・自転車・小舟の絵と、小舟・影の絵は使っていません（マップは2頭身・水の上はアニマに乗るため）
- 道具の効果の数値は、ゲーム用にこちらで決めました
