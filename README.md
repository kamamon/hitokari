# タマモノ見聞録

スマホのブラウザで遊べる、モンスター育成RPGです。
ふしぎな生きもの「タマモノ」と縁を結び、16の道場と覇者の道をこえて、アマツ大陸の覇者をめざします。

## 遊ぶには

GitHub Pages を有効にすると、スマホからそのまま遊べます。

1. このリポジトリの **Settings → Pages** を開く
2. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
3. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります

ホーム画面に追加すると、全画面のアプリのように遊べます。進み具合は端末に保存されます
（メニューの「きろくする」。町や道を移動したときにも自動で保存されます）。
機種変更などに備えて、メニューの「せってい → セーブを書き出す」で文字として控えておけます。

## 操作

| 操作 | 内容 |
| --- | --- |
| 十字パッド | 移動。円のどこを触っても方向が決まり、指をすべらせて向きを変えられます |
| 画面をなぞる | 移動（パッドの代わり） |
| A / 画面をタップ | 話す・しらべる・決定 |
| B | キャンセル。おしながら移動で走る |
| MENU | メニュー（見聞録・タマモノ・もちもの・地図・相性表・きろく・せってい） |

パソコンでは 矢印キー / Z（決定）/ X（キャンセル・走る）/ M（メニュー）で遊べます。

## 内容

- タマモノ 1024種（すべてオリジナル）。進化は最大5回。色違い、伝説のタマモノ24種
- タイプ17種（相性表はメニューでいつでも確認できます）
- 手持ちは4匹まで。それ以上は社の「あずかり帳」へ
- ボールの代わりに「むすび札」で縁を結ぶ（弱らせる・状態異常にすると結びやすい）
- 最初に選べるタマモノは5種
- 町47、街道107、原野・洞くつ・祠60以上の広い大陸
- 道場16、覇者の道は6階層、四天将と覇者
- ウツロ衆との対決をえがくストーリー
- タイプごとに専用の技エフェクト（威力に応じて4段階）
