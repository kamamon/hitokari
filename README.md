# アニマ・クロニクル ― カンテラの旅人 ―

スマホのブラウザで遊べる、洋風ファンタジーのモンスター育成RPGです。
カンテラの灯でふしぎな生きもの「アニマ」と絆を結び、16のギルドと「栄冠への道」をこえて、ルミエール大陸の王者をめざします。

## 遊ぶには

GitHub Pages を有効にすると、スマホからそのまま遊べます。

1. このリポジトリの **Settings → Pages** を開く
2. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
3. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります

ホーム画面に追加すると、全画面のアプリのように遊べます。進み具合は端末に保存されます
（メニューの「きろくする」。町や建物を移動したときにも自動で保存されます）。
機種変更などに備えて、メニューの「せってい → セーブを書き出す」で文字として控えておけます。

## 操作

| 操作 | 内容 |
| --- | --- |
| 十字パッド | 移動。円のどこを触っても方向が決まり、指をすべらせて向きを変えられます |
| 画面をなぞる | 移動（パッドの代わり） |
| A / 画面をタップ | 話す・しらべる・決定 |
| B | キャンセル。おしながら移動で走る |
| MENU | メニュー（博物誌・アニマ・もちもの・あずかり牧場・自転車・地図・相性表・きせかえ・きろく・せってい） |
| 自転車 | 自転車を手に入れると出るボタン。乗る・おりる |

パソコンでは 矢印キー / Z（決定）/ X（キャンセル・走る）/ M（メニュー）/ C（自転車）で遊べます。

## 内容

- アニマ 1024種（すべてオリジナル）。進化は最大5回。色違い、伝説のアニマ24種
- タイプ17種。2つのタイプをもつアニマは375種（相性表はメニューでいつでも確認できます）
- 手持ちは4匹まで。それ以上は牧場へ（メニューからいつでも会えます）
- ボールの代わりに「カンテラ」をかかげ、灯りで絆を結ぶ（弱らせる・状態異常にすると結びやすい）
- 最初に選べるアニマは5種
- 町47、街道107、原野・洞くつ・遺跡60以上の広い大陸
- ギルド16、栄冠への道は6階層、四騎士と王者
- 灯を消してまわる「灰の結社」との対決をえがくストーリー
- タイプごとに専用の技エフェクト（威力に応じて4段階）
- 戦う場所で変わる背景、戦闘中に動いてまばたきするアニマ
- 風にゆれる木と草むら、足あとや波紋、雪・木の葉・火の粉などの空気感

### いまどきの遊びやすさ

- 着せかえ（肌・髪型・髪の色・ぼうし・上着・ボトムス・くつ）。旅のはじめと、メニューからいつでも
- 自転車（最初のギルドでもらえます）
- 連れ歩き（先頭のアニマがうしろをついてきます。話しかけることもできます）
- けいけんちは手持ちのみんなに分配、絆を結んだときにも入る
- 技をえらぶときに相性のめやすを表示
- 技の書は何回でも使える
- 昼と夜（端末の時計にあわせて景色が変わります）
- オートセーブ

連れ歩き・けいけんちの分配・昼と夜・オートセーブは「せってい」で切りかえられます。
